**Tips and Troubleshooting**
* Use Python 3.1.4 since 3.1.5 and above is not tested with Django yet
* Don't put parentheses in file or folder  names. It seems to mess up extensions and running the program
* Don't put spaces in file names or folder names. It might mess up things in Python or the extensions.
* Don't store the project on a cloud drive like OneDrive. When you are working on the project in VS Code, it should be on your local drive like C or D. A lot of conflicts pop up becuase it is trying to sync a lot of files that are changing all the time and it just doesn't work after a lot of frustration. GitHub will take care of the cloud storage and saving different versions.
