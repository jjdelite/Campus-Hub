# US-67 - View an Item's Details

## User story

As a student, I want to open one item and see all of its details in one place so that I can check everything about it without editing it.

| Field | Value |
|---|---|
| Priority | High |
| Sprint # | TBD |
| Story Points | To be agreed in Planning Poker |

## Acceptance criteria

- Given I click an item in my list or calendar, when the detail view opens, then it shows the item's title, type, course, due date and time, priority, and completion state.
- Given the item has subtasks, an attachment link, or a recurrence rule, when I view its details, then I can see all three.
- Given I am on the detail view, when I choose Edit, Duplicate, or Delete, then the matching action starts from that page.
