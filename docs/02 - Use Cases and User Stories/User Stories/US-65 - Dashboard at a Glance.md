# US-65 - Dashboard at a Glance

## User story

As a student, I want to see a dashboard when I log in that shows what is due today, what is due soon, and what is overdue so that I get an instant picture of my day without opening every course.

| Field | Value |
|---|---|
| Priority | Highest |
| Sprint # | TBD |
| Story Points | To be agreed in Planning Poker |

## Acceptance criteria

- Given I am logged in, when I open the home page, then I see sections for Today, Due Soon, and Overdue, plus my upcoming incomplete items.
- Given an item's due date has passed and it is not complete, when I view the dashboard, then it appears in the Overdue section and is visually distinct from items that are not overdue.
- Given I click an item on the dashboard, when the item opens, then I can view or edit its details.
- Given I click the Add button on the dashboard, when the add-item form opens, then I can create a new item without leaving for another page first.
- The dashboard also shows a short summary of my courses.
