# US-66 - Landing Page for Visitors

## User story

As a visitor who is not logged in, I want to see a home page that explains what Campus Hub does so that I can decide to create an account.

| Field | Value |
|---|---|
| Priority | Medium |
| Sprint # | TBD |
| Story Points | To be agreed in Planning Poker |

## Acceptance criteria

- Given I am not logged in, when I open the site, then I see a short explanation of the app and buttons to Sign Up and Log In.
- Given I click Sign Up, when the sign-up page opens, then I can create an account with my name, email, and password (US-01).
- Given I am already logged in, when I open the site, then I go to my dashboard instead of the landing page.
