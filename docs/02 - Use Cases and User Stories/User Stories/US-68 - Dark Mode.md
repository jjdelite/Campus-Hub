# US-68 - Dark Mode

## User story

As a student, I want to switch Campus Hub to a dark mode so that I can plan at night without the bright screen hurting my eyes.

| Field | Value |
|---|---|
| Priority | Low |
| Sprint # | TBD |
| Story Points | To be agreed in Planning Poker |

## Acceptance criteria

- Given I am on the Settings page, when I turn on dark mode, then every page switches to the dark colour palette.
- Given I have dark mode on, when I log out and back in, then dark mode is still on because the choice is saved to my account.
- Given dark mode is on, when I view the calendar, then each item type and priority still has a distinct, readable colour.
