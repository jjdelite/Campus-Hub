# US-69 - Empty-State Guidance for New Users

## User story

As a new student with nothing in my planner yet, I want the empty screens to tell me what to do first so that I can get started without guessing.

| Field | Value |
|---|---|
| Priority | Medium |
| Sprint # | TBD |
| Story Points | To be agreed in Planning Poker |

## Acceptance criteria

- Given I have added no items yet, when I open my planner, then I see a short message explaining the planner is empty and a button to add my first item.
- Given I have added no courses yet, when I open the Courses page, then I see a message and a button to add my first course.
- Given I have nothing due today, when I open my dashboard, then the Today section says so instead of showing a blank space.
